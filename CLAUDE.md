# Project: [Ngesihle Front End Engineering Project]

## Stack
- React (Vite)
- Semantic HTML5
- Vanilla CSS (no framework/preprocessor unless stated)
- Vanilla JS / JSX — no additional state libraries unless added later

## Conventions
- Functional components only, no class components
- One component per file, PascalCase filenames (e.g. `NavBar.jsx`)
- Semantic HTML tags required (`<nav>`, `<main>`, `<section>`, `<article>`, etc.) — avoid unnecessary `<div>` nesting
- CSS: one stylesheet per component, co-located (e.g. `NavBar.jsx` + `NavBar.css`)
- No inline styles except for dynamic/computed values
- 2-space indentation, single quotes, no semicolons omitted

## Commits
- Conventional Commits format: `type(scope): description`
- Types used: feat, fix, docs, style, refactor, chore

## Notes for AI assistant
- Prioritize accessibility (proper ARIA labels, alt text, keyboard navigation)
- Explain non-obvious code choices in comments, briefly
